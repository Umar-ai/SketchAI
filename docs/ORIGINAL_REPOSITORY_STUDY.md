2. In Android Studio, open project root, allow sync, run on device.
3. Record module structure and specific `.java`/`.kt` files and dependencies.
4. Locate the `.tflite` model in assets; determine exact shape/type.
5. Inspect the interpreter initialization, preparation, inference and UI result.
6. Add explanatory code comments in a study copy; avoid publishing someone
   else's project as if it were originally yours.
7. Screenshot repository structure, build success, and original app running.
8. Compare original model input/output pipeline with SketchAI's image input.
